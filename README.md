# 🍫 SI Luxury Chocolate Factory

Welcome to the digital home of **SI Luxury Chocolate**. This repository hosts the first iteration of our premium artisan chocolate showcase.

## ✨ Features
* **Artisan Gallery:** A curated look at our signature truffles.
* **The Process:** Insights into our "bean-to-bar" philosophy.
* **Responsive Design:** Elegant viewing on mobile, tablet, and desktop.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Custom animations for a "velvet" feel)
* JavaScript (Interactive menu)
* Java

## 🚀 Deployment
This site is designed to be hosted via **GitHub Pages**.
